EMPIREON 87.36 — שמירות ענן בחיבור איטי

לחיצה על עיר אויב ללא יחידה מגינה מציעה הפגזה וכיבוש כאשר יחידת ירי יבשתית יכולה לבצע את שתי הפעולות בתור הנוכחי.
בחירה בכיבוש מניעה את היחידה לעיר ומעבירה אותה לשליטת השחקן.

דפדפנים תומכים דוחסים את מצב המשחק וההיסטוריה ב־gzip לפני העלאה.
שמירה ידנית בודקת מה התקבל בענן לאחר שגיאת חיבור ומנסה שוב כשהתא עדיין פנוי או מכיל את אותה גרסה קודמת.
מסך הטעינה ממתין לשמירה האוטומטית האחרונה ומציין אם היא עדיין בתור לאחר ניסיון כושל.
אפשר לטעון שמירות קיימות. פתיחת שמירות חדשות שנדחסו דורשת גרסה 87.36 ומעלה ודפדפן תומך.
בפרויקט שכבר הוגדר לגרסה 87.33 אפשר לדלג ישר להעלאה.

הכנה חד־פעמית לפרויקט חדש
1. פתח את הגדרות ההתחברות בפרויקט והפעל Allow anonymous sign-ins. שמור את השינוי.
   https://supabase.com/dashboard/project/fcuijevvmjvjsaajonyb/auth/providers
2. פתח SQL Editor, העתק את תוכן schema.sql מהחבילה והרץ אותו.
   https://supabase.com/dashboard/project/fcuijevvmjvjsaajonyb/sql/new
   הסקריפט מתאים לטבלה חדשה או לטבלת saved_games מגרסה 87.29 וניתן להרצה חוזרת.
   הוא מוסיף מספר תא ובקרת גרסה ומגביל כל שחקן לגישה לשמירות שלו.
3. בפרויקט חדש יש להגדיר גם את bug_reports. המשחק שולח user_id, bug_description, bug_data ו־game_version.
   המסד קובע את created_at ואת ברירת המחדל new לשדה bug_status.

העלאה ל־GitHub מהמחשב שלך
חלץ את ה־ZIP. מתוך התיקייה שחולצה, ב־PowerShell, הרץ:
py -3 .\Upload_EMPIREON.py
הסקריפט נעזר ב־Git for Windows. הוא מוסיף את גרסת המשחק ומעדכן את הקבצים הנלווים בענף main של ohad-rab2/emp.
אפשר גם להעלות ידנית את קובץ המשחק ואת cloud.js, schema.sql, test-cloud.cjs ו־README_HE.txt לתיקייה הראשית.
הקישור הקבוע למשחק: https://ohad-rab2.github.io/emp/game.html

במשחק
השחקן נכנס למשחק ישירות. בשימוש הראשון בשמירות או בדיווח תקלה המשחק מקבל זיהוי אנונימי אוטומטי.
דיווח תקלה זמין בהגדרות התפריט הראשי ובתפריט שבתוך המשחק. תיאור קצר נדרש.
גרסת המשחק ופרטי אבחון מצורפים אוטומטית. אישור השליחה מופיע לאחר תשובת השרת.
אם השליחה נכשלת, הטקסט נשמר בטופס ואפשר לנסות שוב.
כפתור השמירה הרגיל מציג חמישה תאים במסד הנתונים. פעולות במשחק מעדכנות גם תא שמירה אוטומטי.
כפתור הטעינה בתפריט הראשי ובמשחק קורא מאותו מסד נתונים. ההודעה על שמירה מוצלחת מוצגת לאחר אישור השרת.
בזמן תקלה בשמירה ידנית אפשר לנסות שוב כשהחיבור חוזר. השמירה האוטומטית מנסה שוב כל עוד הלשונית פתוחה.
במצב כזה כדאי להשאיר את המשחק פתוח עד לשמירה מוצלחת או לייצא עותק לקובץ.

שמירות ישנות והעברה בין מכשירים
בדפדפן נשמר אסימון הזיהוי של השחקן. פתיחת דפדפן אחר או מחיקת נתוני האתר מנתקת את הגישה לזהות האנונימית הקודמת.
להעברת משחק אפשר לייצא אותו לקובץ, לייבא במכשיר השני ואז לשמור לתא בענן.
שמירות מענן 87.29 מופיעות אם החיבור הקודם עדיין תקף באותו דפדפן. בחלון הטעינה אפשר לייבא שמירות מהגרסה הישנה אם הן מזוהות במקור שממנו נפתח המשחק. הייבוא משאיר את המקור במקומו.
לבדיקה מקומית של שמירות ודיווחים מול שרת מדומה הרץ node test-cloud.cjs
